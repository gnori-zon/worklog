### worklog
A terminal-based time tracking application built with Rust and Ratatui. Manage projects, track work sessions, and visualize daily activity through an interactive TUI.

#### Building Worklog

##### Requirements

- [Rust](https://www.rust-lang.org/tools/install) (stable toolchain)
- Cargo
- Make

##### Build

Clone the repository:

```bash
git clone https://github.com/gnori-zon/worklog.git
cd worklog
```

Build the release binary:

```bash
make build
```

The executable will be available at:

```text
target/release/worklog
```

Run the application:

```bash
make run
```
